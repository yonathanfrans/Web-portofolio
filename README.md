# Website Portofolio

Website Portofolio adalah sebuah situs web yang memperlihatkan kemampuan, kreativitas, dan pengalaman yang dimiliki oleh individu kepada calon klien, perekrut, atau pengguna lainnya. Website ini dibuat sebagai single-page website, di mana semua informasi akan disajikan dalam satu halaman yang dapat diakses dengan melakukan scroll ke bawah atau menggunakan navigasi yang disediakan.

🔗 **Live Demo**: https://yonathanfrans.up.railway.app/

## ✨ Features

- **Dynamic Content (CRUD)**: Admin dapat menambah, mengubah, dan menghapus data seperti project dan skill.
- **Admin Dashboard**: Halaman khusus untuk mengelola konten website.
- **Dark Mode**: Fitur untuk beralih antara mode terang dan gelap.
- **Responsive Design**: Tampilan optimal di desktop maupun mobile.
- **Project Showcase**: Menampilkan daftar proyek beserta link.
- **Contact Section**: Informasi kontak yang mudah diakses.
- **Hamburger Menu**: Navigasi yang ramah pengguna pada perangkat mobile.

---

## 🧩 Sections

Website ini terdiri dari beberapa bagian utama:

- **Home / Landing Page**  
  Menampilkan profil singkat, nama, dan navigasi utama.

- **About Me**  
  Berisi informasi tentang latar belakang, pendidikan, dan minat.

- **Skills**  
  Menampilkan daftar keterampilan yang dimiliki.

- **Projects**  
  Menampilkan daftar proyek yang telah dibuat.

- **Contact**  
  Menyediakan informasi kontak dan media sosial.

- **Admin Panel**  
  Digunakan untuk mengelola konten website (CRUD data).

## ⚙️ Installation

Untuk menginstal dan menjalankan proyek ini secara lokal, ikuti langkah-langkah berikut:

1. Clone repositori ini:
    ```bash
    git clone https://github.com/yonathanfrans/Web-portofolio.git
    cd Web-portofolio
    ```
2. Install Dependency
    ```bash
    composer install
    npm install
    ```
3. Konfigurasi Environment
    ```bash
    cp .env.example .env
    ```
    Lalu sesuaikan konfigurasi database di file .env
4. Generate Key
   ```bash
    php artisan key:generate
   ```
5. Migrasi Database
   ```bash
    php artisan migrate
   ```
6. Jalankan Server
   ```bash
    php artisan serve
   ```
